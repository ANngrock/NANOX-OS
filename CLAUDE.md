# Входная инструкция для Claude Code

Работай по `AGENTS.md`. Актуальная архитектура и порядок реализации находятся в `docs/`, а не в старом корневом `ARCHITECTURE.md` или пересказах предыдущих чатов.

Прочитай последовательно:

1. `docs/START-HERE.md`.
2. `docs/STATUS.md`.
3. `docs/adr/0001-platform.md`.
4. `docs/specs/BOOT-M0.md`.
5. `docs/specs/TESTING-REPLAY.md`.

Первое задание — довести M0 до работающего образа и сохранённых результатов проверки. Язык, привилегии Core и первая виртуальная платформа выбраны; повторный архитектурный опрос не нужен.

Среду WSL и наличие Nix проверь по факту. Не отсоединяй устройство по старому номеру `PHYSICALDRIVE2`: эти сведения перенесены из чужого сообщения и не подтверждены.

Команды `cargo xtask ...` в документах — интерфейс, который предстоит реализовать. Сейчас они не существуют. В этом пакете документации нет готового bootloader/kernel и нет успешных запусков QEMU.

Сохрани актуальную историю и изменения репозитория при подготовке checkout на Linux filesystem. Не начинай новый несвязанный Git-репозиторий.
